## 2. فحص بيئة التطوير

توجد بيئتان: بيئتي السحابية (حيث أعمل)، وخوادم GitHub Actions (خدمة GitHub التي تبني المشروع وتختبره تلقائياً عند كل رفع للكود، وتُسمّى CI أي "التكامل المستمر").

| الأداة | البيئة السحابية | GitHub Actions | التحقق |
|---|---|---|---|
| Java (JDK) | OpenJDK 21.0.13 ✅ | Temurin 21.0.13 ✅ | `java -version`، وسجل التشغيل |
| Gradle (أداة البناء) | 8.14.3 مثبّت؛ المشروع يستخدم Gradle 9.6.0 عبر الـ wrapper ✅ | 9.6.0 ✅ | سجل التشغيل |
| Kotlin | 2.4.21 (آخر إصدار مستقر على Maven Central) ✅ | 2.4.21 ✅ | بيانات Maven Central |
| Android SDK (حزمة أدوات أندرويد) | **غير متوفر ولا يمكن تثبيته** ❌: سياسة الشبكة تحجب `dl.google.com`، ومستودع Google Maven يحوّل إليه | **متوفر مسبقاً** ✅ في `/usr/local/lib/android/sdk`، وتوجد منصات حتى `android-37.2` | خطأ 403 من وكيل الشبكة؛ سجل تشغيل CI |
| Android Gradle Plugin (إضافة البناء من Google) | لا يمكن تنزيله محلياً ❌ | الإصدار 9.2.1 يعمل ✅ | سجل CI |
| أدوات البناء (build-tools) | — | 36.0.0 ✅ | سجل CI |
| أجهزة اختبار | **لا يوجد** هاتف Android متصل. حاسوبك المحمول مرتبط بالمشروع لكنه كان غير متصل | لا توجد أجهزة (المحاكي ممكن لاحقاً) | `list_devices` |

### هل يمكن إعداد GitHub Actions؟ نعم، وتم التحقق عملياً

شغّلتُ ستّ عمليات بناء على GitHub Actions أثناء الفحص. الدروس المستفادة (كلها موثقة في سجلات التشغيل على GitHub):

1. أداة `android-actions/setup-android@v3` فشلت (تحاول تثبيت حزمة قديمة اسمها `tools`)، والحل استخدام حزمة أندرويد المثبّتة مسبقاً على الخادم.
2. إضافة Kotlin يجب أن تُحمَّل مع إضافة Android في نفس "محمّل الأصناف" (classloader) وإلا يفشل البناء.
3. مكتبات Compose في BOM ‏2026.09.00 تتطلب `compileSdk 37` (أي البناء مقابل Android API 37)، واسم الحزمة على الخادم هو `platforms;android-37.0` وليس `android-37`.
4. بعد هذه الإصلاحات **تمت ترجمة كود تطبيق Android بنجاح** على الخادم، وفشل فقط اختبار واحد في التطبيق بسبب استيراد خاطئ لمكتبة الاختبار (أُصلح في المسودة المحفوظة).

**الخلاصة:** البناء الكامل لتطبيق Android ممكن عبر GitHub Actions دون أي تكلفة إضافية في المستودعات العامة، ومع حصة مجانية شهرية في المستودعات الخاصة. البناء المحلي في بيئتي السحابية ممكن فقط لكود Kotlin الخالص (المحرّك)، إلا إذا سمحتَ بالنطاق `dl.google.com` في إعدادات الشبكة (اختياري، غير ضروري).

### ما لم يمكن فحصه

- **السلوك الفعلي على هاتف حقيقي** (التشغيل في الخلفية، قيود البطارية لدى الشركات المصنّعة، سلوك WhatsApp مع الروابط والإشعارات). يحتاج هاتفاً متصلاً بحاسوبك أو محاكياً على CI. هذا شرط قبل وصف أي ميزة بأنها "تعمل".

## 4. مسودة الكود المحفوظة (لم تُدمج)

| الوحدة | المحتوى | الحالة |
|---|---|---|
| `core:model` | أنواع المجال: مستويات الخطورة، القدرات، حالات المهمة، حالات التنفيذ (محاولة / مقبول / مكتمل / متحقق منه) | 49 اختباراً ناجحاً محلياً |
| `automation:actions` | كتالوج الإجراءات وسجلّها: يرفض أي إجراء غير مسجّل أو معاملات غير صالحة | ضمن الاختبارات أعلاه |
| `automation:policies` | قواعد الموافقة: منخفض تلقائي، متوسط/عالٍ بموافقة، حرج ممنوع دائماً، زر إيقاف طارئ | ضمن الاختبارات |
| `domain:mission` | آلة حالات المهمة، وقرار الاستعادة بعد تعطل التطبيق دون تكرار الإرسال | ضمن الاختبارات |
| `domain:agent` | محلّل خطط JSON من النموذج مع إصلاح محدود، ومدقق الخطط، وعزل المحتوى غير الموثوق | ضمن الاختبارات |
| `domain:providers` | واجهات مزوّدي الذكاء الاصطناعي، وملفات الذكاء (BASIC/STANDARD/ADVANCED) | ضمن الاختبارات |
| `app`, `core:design` | هيكل تطبيق Compose بالثيم الداكن والعربية/الإنجليزية | تُرجم بنجاح على CI |

لاستعادتها لاحقاً: `git fetch <bundle> foundation-draft`. لن أستخدمها قبل موافقتك على المرحلة الأولى.
