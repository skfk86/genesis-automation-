# خارطة طريق التطوير — GENESIS

كل مرحلة تنتهي بتقرير يتضمن: ما نُفّذ، الملفات المتغيرة، نتائج البناء، نتائج الاختبارات، القيود المتبقية، والمرحلة التالية. لا تبدأ أي مرحلة قبل موافقتك على السابقة، ولا توصف ميزة بأنها مكتملة دون دليل اختبار.

| المرحلة | المحتوى | شرط الإكمال |
|---|---|---|
| **0. الاستكشاف (الحالية)** | فحص المستودع والبيئة، دراسة Android وGoogle Play والتطبيقات الخارجية ومزوّدي الذكاء الاصطناعي، نموذج التهديدات | الملفات الستة + موافقتك |
| 1. التصميم المعماري | مواصفات المنتج، هيكل الوحدات (modules)، نماذج المجال، آلة حالات المهمة، نموذج الصلاحيات، معمارية الأمان، نظام التصميم (ألوان، خطوط، مكوّنات، RTL) | وثائق معتمدة منك + نماذج مجال مختبرة |
| 2. الأساس التقني | مشروع Android، Compose، التنقل، Hilt (حقن الاعتماديات)، Room (قاعدة البيانات)، DataStore (الإعدادات)، تخزين المفاتيح المشفر، GitHub Actions | بناء ناجح على CI + اختبارات قاعدة البيانات والتخزين وواجهة الترحيب والرئيسية بالعربية والإنجليزية |
| 3. بوابة الذكاء الاصطناعي (BYOK) | محوّلات Claude وOpenAI وGemini والمتوافقة مع OpenAI؛ إضافة/اختبار/حذف مزوّد؛ اختيار النموذج؛ تقييم القدرات؛ معالجة الأخطاء؛ عرض الاستهلاك؛ إفصاح التكلفة | اختبارات لكل نوع خطأ (مفتاح خاطئ، تجاوز الحد، انقطاع، مخرجات مشوهة) + قائمة اختبار حي تنفّذها أنت بمفاتيحك |
| 4. ذكاء الوكيل | فهم النية، إدارة السياق وميزانية الرموز، التخطيط والتقسيم، القوالب المحلية لـ BASIC، أسئلة التوضيح، أداة تقييم النماذج | اختبارات بنماذج وهمية تحاكي الضعيف والمتوسط والقوي + أول نتائج تقييم حقيقية |
| 5. محرّك المهام | التنفيذ مع مهلة وإلغاء، التحقق، الاستعادة، حفظ كل انتقال، إيقاف مؤقت/استئناف/إلغاء/إيقاف فوري، واجهة الموافقة، شاشات المهام | اختبارات تعطل التطبيق ومنع الإرسال المكرر |
| 6. أتمتة Android | محوّلات Intents والروابط العميقة والنظام؛ المشاركة؛ الإشعارات (اختيارية مع إفصاح)؛ التقويم | **اختبارات على هاتف حقيقي** لكل قدرة؛ تحديث مصفوفة القدرات بالأدلة |
| 7. منشئ الأتمتة | المحفّزات (وقت، إشعار، إجراء المستخدم)، الشروط، الإجراءات، المحرر، السجل | اختبار سلوك الخلفية على إصدارات Android مختلفة |
| 8. ذكاء متقدم | تعدد المهام، تحسين السياق، تبديل النموذج أثناء المهمة، القوالب | مقارنة نتائج التقييم بين فئات النماذج |
| 9. الأمان والإنتاج | تدقيق أمني، مراجعة خصوصية، أداء، توافق، تحسين الواجهة، نسخة إصدار | قائمة الإصدار كاملة |
